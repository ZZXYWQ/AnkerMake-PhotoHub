# AnkerMake PhotoHub

**从图片创作、分层工艺到打印准备，在 AnkerMake 的同一张画布里完成。**

PhotoHub 为 AnkerMake 补充图片编辑、PSD 分层导入、轮廓处理、逐层 CMYK 墨路测试、超长卷材打印和本地 AI 浮雕生成。编辑后继续使用原来的账号、工艺设置与打印流程。

**0.8.7.4 FlatPreviewFix 公开测试版** · AnkerMake Studio **5.1.3** · 编辑器 **1.25.04** · Windows **10/11 x64**

[下载安装包](https://github.com/ZZXYWQ/AnkerMake-PhotoHub/releases/tag/v0.8.7.4-flatpreviewfix-public-beta) · [新手安装与升级教程](docs/新手安装与升级教程.md) · [完整功能与验证范围](docs/FEATURES.md)

## 围绕一张图，完成一套 UV 工作流

| 阶段 | PhotoHub 提供什么 | 可以用来做什么 |
| --- | --- | --- |
| 图片创作 | PS 式图片编辑、选区与蒙版 | 在原画布新建、修改和整理素材 |
| 分层工艺 | PSD 分层导入、逐层工艺及工艺合成 | 把一个设计拆成可以独立处理的打印图层 |
| 墨路试验 | 每层 C、M、Y、K 单路或组合选择 | 进行单色出墨和分层墨路测试 |
| 长卷输出 | 超限导入解禁、原版与超限两种打印准备算法 | 保留原始像素，准备超长卷材设计 |
| 立体效果 | 本地 AI 深度图、AI 笔触纹路与传统生成方式 | 为平面图片生成可用于原版工艺的高度图 |

## 图片编辑：把常用的 PS 式操作放进原画布

新建图片或继续编辑已有图片，使用画笔、橡皮、魔术棒、矩形/椭圆选区、套索、羽化、蒙版、仿制与取样修复、渐变、色阶、曲线和常用调整滤镜。

工具接入顶部菜单、左侧 PhotoHub 工具栏和原版右键菜单，图片编辑无需进入独立编辑窗口。具体对象类型、尺寸及编辑限制见完整功能表。

## PSD 分层：让图层成为工艺单元

把 PSD 中的像素图层导入 AnkerMake，保留每层的位置、透明度与顺序，再分别设置原版工艺和墨路。

复合工艺提供两种合成方式：**重叠模式**保留重叠区域较高的工艺，**顶面模式**按上层非透明像素决定工艺；顶面模式还可选择是否忽略半透明像素。支持范围与未验证项目见 [功能说明](docs/FEATURES.md)。

## CMYK 墨路：逐层进行单路与组合测试

每个图层可分别选择 C、M、Y、K 的单路或组合，用于单色出墨、墨路检查和分层打印试验。一个图层的选择不会代替其他图层的设置，白墨与光油仍沿用该层原版工艺。

这是实验性打印控制功能。历史数据测试不能代替当前设备、工艺和完整打印链路的实物验收。

## 超长打印：导入解限，加上专用优化路径

解除原软件的图片导入尺寸校验，保留原始像素；打印按钮右侧箭头提供 **“原版打印算法（普通图片）”** 和 **“超限图片优化算法”**。切换算法不会重新生成浮雕或改变现有工艺。

**当前版本的超长打印必须：横向长图导入 → 在 AnkerMake 软件里面旋转 90° → 核对 W/L 与方向 → 选择“超限图片优化算法”。**

旋转必须在软件内完成，不能先在外部转成竖图再直接导入。竖向直接导入的超长路径仍不可靠。用户已反馈清明上河图按上述流程可正常打印；这不代表所有方向、图片或工艺均已验收。详细步骤见下方操作要求。

## 本地 AI：生成浮雕深度或笔触纹路

安装包内置离线模型与 CPU 运行组件，无需另装 ComfyUI 或下载模型，也不消耗云端生成积分。

- **AI 深度图**：分析画面层次，为浮雕提供深度来源。
- **AI 笔触纹路**：提取线条与笔触结构，为纹理工艺提供高度来源。
- 两种 AI 方式二选一；另外保留 **连续面浮雕、墨线增强、灰度映射、细节增强** 四种传统本机方式。

生成结果直接接入原版工艺设置与预览。古画、小人物、印章和复杂透视可能误判，生成结果与艺术效果仍需自己检查。

## 下载安装

下载 [0.8.7.4 Release](https://github.com/ZZXYWQ/AnkerMake-PhotoHub/releases/tag/v0.8.7.4-flatpreviewfix-public-beta) 中的单个 EXE：

`ZZXlab-AnkerMake-PhotoHub-0.8.7.4-FlatPreviewFix-Win10-Win11-x64-Setup.exe`

## 超长打印的方向要求

1. 准备横向长条原图，宽度大于高度，例如 51160×1924 像素。
2. 保持横向状态导入 AnkerMake，再在软件画布中旋转 90°，使长边沿卷材进给方向排列。
3. 核对最终打印宽度 W、卷材长度 L、比例及画面朝向。
4. 选择 **“超限图片优化算法”**，再按原版准备流程操作。

**必须横向导入，再在软件里面转。外部先转成竖图再导入不属于当前已确认可用的流程。**

2026-11-28 的用户反馈确认该流程可以正常打印清明上河图；本轮维护未额外执行实物打印，任意方向和完整机器端数据处理仍未完成独立验收。

## 卸载与项目说明

先退出 AnkerMake，在 Windows 设置 → 应用 → 已安装的应用中选择 **“ZZXlab · AnkerMake PhotoHub”** 卸载，或使用开始菜单 **“ZZXlab → 卸载 PhotoHub”**。卸载恢复原版文件，保留用户设计及生成结果。

PhotoHub 是第三方社区插件，继续使用原软件账号和打印流程。原软件部分目录、进程和域名仍保留历史名称 eufyMake，源码保留这些兼容标识。安装包不包含原版软件、账号信息或测试用 PSD。
