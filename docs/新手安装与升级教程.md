# AnkerMake PhotoHub 插件：新手安装与升级教程

适用版本：**PhotoHub 0.8.7 公开测试版**。功能版本为 0.8.7，安装器文件版本为 0.8.7.0。请按顺序操作；首次检查不需要实际打印。功能、入口和验证状态逐项见 [功能清单](FEATURES.md)。

> **本项目所有公开版本均为测试版，可能存在较多 Bug；不保证及时更新或修复，没有固定更新计划。请先备份设计，并自行评估是否适合自己的工作。**

## 一、先分清三个版本

| 名称 | 是什么 | 本插件要求 |
| --- | --- | --- |
| AnkerMake Studio | 电脑上原本用于登录、设计和 UV 打印的软件 | **5.1.3** |
| 内置编辑器 | Studio 里打开设计时使用的画布资源 | **1.25.04**，相关在线模块也须通过校验 |
| PhotoHub | 本仓库提供的图片/PSD/轮廓/墨路扩展 | **0.8.7 公开测试版** |

三者不是同一个版本号。安装 PhotoHub **不会**替你升级 Studio，也不会把不兼容的编辑器变成受支持版本。

本包只支持 Windows 10 / 11 **x64**。旧版和其他新版 Studio 均不在本版适配范围。PhotoHub 0.6.0 及更早版本不要用于逐图层分墨路任务。

## 二、下载正确的原版软件

1. 打开官方 [Anker Make Studio 下载页](https://www.eufymake.com/eufymake-studio)。这是官方地址；网页域名仍保留历史品牌名。
2. 页面中找到 **Download for Windows (UV)**，选择 **UV**，不要选择 Windows (3D)、MacOS 或 Legacy Version。
3. 完整安装包可能比软件内更新版本旧：本机从官方完整包安装的是 5.0.4，随后使用原版更新器升级到 5.1.3。请以最终运行中的版本为准。下载后查看安装文件的版本信息。文件名有时仍带历史品牌名，判断依据是官方来源、UV 用途和实际版本，不能只看文件名。
4. 双击官方安装文件，选择语言和安装位置，按官方安装向导完成。
5. 打开 Studio，按原版方式登录。PhotoHub 不提供新账号，也不需要你把账号或密码填进插件。

**官方网页会随时间更新，下载按钮不保证永远提供 5.1.3。** 如果完整安装包版本较旧，请先安装原版，再按原版提示更新至 5.1.3，确认能正常启动后再装插件。如果最终运行版本不是 5.1.3，请等待对应适配版。不要从本仓库寻找原版软件或 ICC；本项目不分发这些文件。

官方参考：[软件下载页](https://www.eufymake.com/eufymake-studio)、[软件用户指南](https://wiki.eufymake.com/en/softwaremanual)、[5.0 官方更新说明](https://wiki.eufymake.com/en/software/update/5-0)。本教程核对日期：2026-11-03；官方页面的布局和菜单文字可能变化。

## 三、原版 Studio 怎么升级、怎么看版本

如果已经装好了 Studio：

1. **先等当前打印任务完成。** 不要在打印中关闭软件、安装插件或升级原版。
2. 打开当前设计，按 `Ctrl+S`。如果弹出提示，选择“保存到本地”，记住 `.empf` 文件放在哪里。
3. 使用文件资源管理器，为重要 `.empf` 设计另外复制一份备份。
4. 在 Studio 的“文件 / 设置”或“帮助 / 关于”中查看当前版本。不同原版版本的菜单位置可能不同；标题栏也可能直接显示，例如 `Anker Make Studio-5.1.3`。
5. 若有“检查更新”，按原版提示操作；也可以从前述官方 **Windows (UV)** 下载入口获取原版安装器。
6. 升级完成后重新打开 Studio，再次核对是否为 **5.1.3**。若官方升级到了其他版本，请停止安装本版插件，等待对应适配。

如果已装 PhotoHub，需要更新原版 Studio：先保存项目并退出软件，使用原 PhotoHub 安装包卸载扩展，再更新原版。不要直接把旧插件文件复制进新版原版目录。

## 四、内置编辑器从哪里下载或升级

**不需要另外寻找“PhotoHub 编辑器安装包”，也不需要单独安装 PhotoCraft。** 本插件的编辑工具直接在 Studio 原画布中使用。

Studio 的原版编辑器资源由原软件加载/维护；在线画布还可能随官方服务更新。用户不应从本仓库下载一份原版编辑器覆盖进去。

查看本地已缓存的编辑器版本：

1. 打开 Windows 文件资源管理器。
2. 点击上方地址栏，粘贴下面这行，按回车：

   ```text
   %APPDATA%\eufyMake Studio Profile\cache\offline\web_res
   ```

3. 找到 `current_version.txt`，用记事本打开。里面可能是 `1.25.04`，也可能是包含该版本的完整目录路径。
4. 也可以查看同目录的 `versions` 文件夹，核对当前使用的版本。**本版要求 1.25.04**，不是看到这个文件夹存在就说明当前正在使用它。
5. 如果找不到缓存，先正常联网打开 Studio 中的设计画布，让原软件完成正常加载，再关闭 Studio 后查看。

`eufyMake Studio Profile` 是原版沿用的历史目录名，公开项目名称仍为 **AnkerMake PhotoHub 插件**。

若版本不符：通过原版更新流程获取资源，或咨询官方支持。**不要修改 `current_version.txt`、改文件夹名、删除缓存来伪装成 1.25.04。** 插件还会核对实际资源哈希；线上资源改变后也可能停止接入，需要等待适配。

## 五、取得本次 0.8.7 安装包

本次是本地构建，尚未更新 GitHub。请使用交付给你的单个 EXE：

`ZZXLAB-AnkerMake-PhotoHub-0.8.7-LocalModesFix-Win10-Win11-x64-Setup.exe`

不要用旧 GitHub Release 的 0.7.x 安装包覆盖编辑器 1.25.04。后续公开发布后，在仓库右侧 Releases 进入对应版本，从 Assets 下载 EXE，源码 ZIP 不能代替安装器。

安装包已包含运行环境，不需要额外安装 Python、Node.js 或另一个图片编辑器。

## 六、安装：一步一步操作

1. 先等当前打印结束，保存设计，完全退出 AnkerMake Studio。
2. 双击 `ZZXLAB-AnkerMake-PhotoHub-0.8.7-LocalModesFix-Win10-Win11-x64-Setup.exe`。
3. 确认欢迎页显示 ZZXLAB 和 0.8.7 公开测试版，点“下一步”。
4. 阅读测试版说明，选择插件管理文件的安装位置。AI 模型和运行组件已打包，不需要你另装环境。
5. 确认 AnkerMake 原版目录（包含 `eufymake studio.exe`）。安装器会读取当前用户的编辑器缓存并校验版本。
6. 选择开始菜单位置，点击“安装”，等待备份、复制和校验完成。
7. 完成后从开始菜单的“ZZXLAB → AnkerMake + PhotoHub”或桌面插件入口启动。入口使用 ZZXLAB 图标。

**只需要这一个 EXE。** 它不是原版 AnkerMake 安装器；请先装好受支持的原版软件。Windows 系统适配与编辑器版本校验是两回事。

## 七、第一次确认插件正常：不实际打印

1. 先在普通编辑画布测试，不要在正在打印的页面测试。
2. 检查顶部 PhotoHub 工具菜单、左侧 PhotoHub 入口和原版右键菜单中的 PhotoHub 子菜单。
3. 新建一张小图片，确认能在原画布看见。
4. 选中一张图片，打开图片编辑功能，做一处明显的小改动，点击“完成编辑 / 应用”，确认修改回到画布。
5. 用一张轮廓简单的测试图做“图片转轮廓”，再右键进入轮廓形状编辑，确认节点操作有效。
6. 按 `Ctrl+S` 保存，关闭该测试设计，再重新打开，确认内容还在。
7. 此时**不必按“打印”**。本次公开验证证明的是离线打印数据流程，不代表你的机器和材料已经做过实物验证。

## 八、PSD 分层导入和每层墨路检查

1. 建议先准备一个只有 2～4 层、8 位 RGB / 灰度、普通像素图层的 PSD 副本。
2. 通过 PhotoHub 的 PSD 导入入口选择该文件，等导入结束。
3. 打开原版左侧“图层”，逐一选择各层，检查位置、上下顺序和透明度。
4. 在原版工艺设置中为每层选需要的平面、纹理等工艺。
5. 在“当前图层 CMYK”中，为第一层只选 C、第二层只选 M、第三层只选 Y、第四层只选 K（或选择你需要的组合）。
6. 来回切换这些图层，确认勾选框显示各自的设置，而不是所有层一起变化。
7. 按 `Ctrl+S` 保存为 `.empf`，重新打开后再检查一次。

`.psd` 是导入的源文件；在 Studio 内的后续设置请保存到原版项目 `.empf`，不要假定插件会回写原始 PSD。

未选彩色通道会在最终喷点数据里清零，但画布 RGB 颜色及原版预估墨量不一定随之变化；“看上去颜色没变”不能说明设置无效。半透明重叠处采用参与合成图层所允许墨路的并集；完整规则见 README。

## 九、从旧版 PhotoHub 升级

1. 0.6.0 及之前版本不要继续用于逐图层分墨路任务。
2. 等现有打印任务结束，保存所有打开的设计并完全退出 Studio。
3. 下载 **0.8.7 公开测试版** 的单文件安装器，可直接覆盖安装已有 PhotoHub，无需先卸载。
4. 运行安装器，确认原版安装位置正确，点击“安装”。通常不需要先卸载旧版。
5. 出现备份/哈希异常时，不要手动删备份目录，也不要直接拷贝文件覆盖；先查看日志并提交脱敏问题报告。
6. 重新打开原 `.empf`，逐层检查墨路勾选和原版工艺，然后保存。

旧项目没有 PhotoHub 墨路字段时默认 C/M/Y/K 全选。升级不会自动猜测你希望某层使用哪一个墨路。

## 十、卸载与常见问题

### 卸载

等打印结束 → 保存设计 → 退出 Studio → Windows 设置“已安装的应用” → ZZXLAB · AnkerMake PhotoHub → 卸载。卸载会恢复原版文件，用户设计和生成结果保留。

### 安装窗口打不开

确认下载的是 EXE 而不是源码压缩包；确认 Windows 10/11 x64、下载完整、文件来源和校验正确。不要使用 ARM64 或 32 位机器强行尝试。

### 点击安装后报版本不支持

核对 Studio 5.1.3、编辑器 1.25.04，确认下载了 UV 版本。不同文件哈希，即使界面版本号相同，也可能是不同构建。把脱敏错误信息提交到 Issues，等待适配。

### 菜单没有出现

确认安装成功后真正退出并重开过 Studio；进入普通编辑画布，等待资源加载。原版升级或在线资源变化可能使旧适配失效，不能靠修改版本文件解决。

### 点击桌面或任务栏图标没有窗口

先确认使用的是 **0.8.7** 安装器，文件版本为 **0.8.7.0**；保存设计并退出 Studio 后可覆盖修复。此版修复启动脚本路径不可见及已有窗口未恢复的问题，本机实际双击冷启动约 8 秒，仅为单机结果，不保证所有启动故障均已解决。

新安装的稳定启动日志默认位于 `%USERPROFILE%\AnkerMakePhotoHub\launcher.log`。从旧安装升级时可能保留已有受管理的启动目录，以快捷方式属性中 `-File` 后脚本所在目录为准；请勿自行改写该路径或哈希。

### 墨路勾选框没有显示

先选中**单个**图层，进入原版墨水/工艺设置面板。不要在多选、预览或打印页里寻找普通编辑面板。切换层后应显示各自的设置。

### 提交问题时写什么

写插件版本、Studio 版本、编辑器版本、Windows 版本、操作步骤、预期与实际结果。日志常见于：

```text
%LOCALAPPDATA%\EufyPhotoCraftBridge\setup.log
```

这是历史兼容目录名。只提交必要且脱敏的错误片段；不要上传 token、账号信息、私有设计或未经许可的图片。

## 5.1.3 启动兼容说明

本机远程桌面环境下，原版默认启动曾出现 MESA OpenGL 切换警告；原版自带 `--no-sw-renderer` 参数已用于桌面、开始菜单和任务栏入口，连续两次启动及现有四图层设计加载通过。插件启动和卸载都会保留这一参数。此记录仅代表本机环境验证，不代表已验证所有显卡和远程桌面环境。

PhotoHub 0.7.0 使用用户目录中的稳定启动入口；原版 OTA 更新后会重新读取当前编辑器路径。遇到尚未适配的编辑器时，回退原版，避免加载旧版补丁。

## 整张长图导入（0.8.7）

1. 安装后从桌面原来的 Anker Make Studio 或 PhotoHub 入口启动，打开普通编辑项目，等待 PhotoHub 菜单出现。
2. 开启左下角“解除图片限制”，直接使用原版左侧“导入”选择未切割的原始 PNG、JPEG 或 WebP。不要先缩小或切割图片。
3. 物理尺寸由文件像素和 DPI 决定，保持原尺寸，不自动适应画布。超出当前画布时，先核对卷材和打印宽度，再由你设置需要的实际打印尺寸。
4. 长图仍是一个原版图片图层，选择后在右侧使用原版工艺。长图画布使用完整原图，避免清晰后又换成低清预览。
5. 安装包不代表任意固件、内存或长度都已通过实物验收；先保存设计、检查预览和工艺数据。出现问题可卸载恢复原版，设计文件保留。


## 本机浮雕：传统方式与两种 AI 生成方式

选中图片 → 右侧“本机浮雕” → 开启 → 在“生成方式”选择一项：

- **连续面浮雕**：平缓连续起伏。
- **墨线增强**：突出墨线和局部笔画。
- **灰度映射**：按明暗映射高度。
- **细节增强**：增强局部纹理。

上述四项无需 AI 模型；下面两种 AI 方式互斥使用：

- **AI 深度图**：Depth Anything V2 Small 识别主体层次，生成连续的相对高度，不叠加线条纹理。
- **AI 笔触纹路**：TEED 学习模型识别暗线、轮廓和细纹，生成线条高度，不混入主体深度。可在更多参数中调节纸面抑制。

点击“生成浮雕”后再点“预览浮雕”。生成不会自动打印；使用原版撤销可恢复上一个高度图。两种模式的模型及 CPU 运行组件已放进同一个安装包，运行时不下载权重、不依赖 Python 或 ComfyUI。

长卷采用重叠区域融合，结果保留原图坐标和输出像素规格。AI 的分析分辨率会限制细节，不等于凭空恢复原图没有的三维信息。“更多参数 → 画面朝向”仅改变模型观看方向，结果会转回打印坐标。

古画、印章、小人物和散点透视可能误判；AI 笔触也可能识别文字和污渍。请先预览，生成测试通过不等于艺术效果或实物打印已验收。

## 打印流程：与浮雕生成分开

- 左侧“图片限制”控制超限图片导入，不是打印算法。
- 黑色“打印”按钮右侧箭头：普通尺寸选“原版打印算法（普通图片）”；超长、超大图片选“超限图片优化算法”。
- 切换打印流程不重算高度，不改变原图、位置、尺寸、厚度、工艺或逐图层 CMYK。
- 平面彩印保持平面工艺，不需要生成浮雕。每个图层的 C、M、Y、K 在“当前图层 CMYK”独立选择。
