# AnkerMake PhotoHub 插件 0.6.1 公开测试版

**本项目所有公开版本均为测试版，可能存在较多 Bug。不保证及时更新或修复，没有固定更新计划。请先备份设计，自行评估。**

此版本作为 Public Beta / Pre-release 发布，不是稳定版。仅适配 **AnkerMake Studio 5.0.4 + 编辑器 1.22.03 + Windows 10/11 x64**。其他新旧宿主不能使用；不要通过修改版本号或跳过哈希校验强行安装。

**PhotoHub 0.6.0 及更早版不要用于逐图层分墨路任务，请升级到 0.6.1。**

## 下载哪个文件

普通使用者只需下载 Assets 中的：

`PhotoHub-AnkerMake-Plugin-0.6.1-Public-Beta-Win10-Win11-x64.exe`

`SHA256SUMS.txt` 用于核对下载文件。GitHub 自动提供的 Source code 压缩包供开发者使用，不能当作安装包直接安装。

安装包内附许可证、第三方声明、新手安装与升级教程及更新记录，不包含原版软件、原版分色 DLL、ICC 或用户设计。

## 使用与升级

请先阅读 [从零开始的安装与升级教程](https://github.com/ZZXYWQ/AnkerMake-PhotoHub/blob/main/docs/新手安装与升级教程.md)，其中写明官方原版下载入口、UV/3D 下载项区分、Studio/编辑器版本检查、安装、首次测试、更新、卸载和排错。

现有打印任务结束 → 保存所有设计 → 完全退出 Studio → 运行安装包选择“安装 / 升级” → 重开项目并逐层核对设置。
