PhotoHub is an unofficial extension. The current installer does not bundle the standalone PhotoCraft application, the eufyMake host, ICC profiles, or proprietary host DLLs.

The bridge executable bundles Python, Pillow, and the PyInstaller runtime.
Their license texts are included in licenses/. PyInstaller's bootloader
exception permits distribution of applications built using PyInstaller.

eufyMake / Anker Make Studio are third-party trademarks. This package is an
unofficial local integration. It contains targeted patch instructions, not
the proprietary host application bundle. Login and printing remain in the host.

PSD import uses ag-psd 31.0.3 (https://github.com/Agamnentzar/ag-psd), with pako and base64-js. Full dependency licenses follow. PSD parsing runs locally in a Web Worker.
