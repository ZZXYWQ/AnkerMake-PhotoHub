# 0.8.7.3 LongRollFix3 验证范围

全部为公开测试版，可能有较多 Bug，不保证及时更新和修复。

- 适配 AnkerMake Studio 5.1.3、编辑器 1.25.04、Windows 10/11 x64；其他宿主版本不支持。
- 撤回 0.8.7.2 的分段高度重写。运行时观察发现设备控制布局使用整卷尺寸，该字段不能按独立桌面 RIP 的逐段布局解释。
- 保留超长源图的可见范围绘制修复，保留原图像素、画布几何、工艺和每层墨路。
- 修复重复生成时原地反转 cutList 与 rollSegmentSizes，改为配对复制并按原打印方向排序；重复生成顺序稳定。
- 全套 JavaScript 回归及精确模块适配检查通过。
- 此前平面 1924×51160、约 280×7445mm 长图完成全部 74 段生成及回拼；此检查不包含设备端处理。
- 正式宿主接收过一个真实 TAR；捕获的宿主输入与网页交出字节 SHA256 完全一致。该次传输未完成后续分段，不能代表最终机器数据验证通过。
- 后续测试停在本地传输回执阶段。诊断期间的临时网络拦截已清除；未下发实物打印。
- 原生网络 SDK 传输和设备固件对完整 74 段的处理尚未验证；未进行实物打印验收。

**条纹是否彻底修复尚不能下结论，暂不建议使用整卷耗材进行实物长图打印。**

单 EXE 安装前请保存设计并完全关闭 Studio。Windows 设置“已安装的应用”中的 PhotoHub 可卸载插件，不删除用户设计。
