## 验证标注

- **已实现**：源码提供该功能；本轮并未逐个对所有原版菜单做实机复测。
- **本轮实际生成通过**：四种传统方式在已安装桥接器上用合成小图生成，尺寸、非空范围、SHA256 正确；未实际打印。
- **实验性 AI**：两种模型已内置，前轮完整长图 CPU 输出通过；识别层次、美学效果和打印质量不保证。
- **数据/回归验证**：相关自动夹具覆盖像素、轮廓、CMYK、长图、预览和打印路由；历史 PSD PRN 零墨路结果不能当成本轮所有工艺均实测。

## 卸载：按顺序操作

1. 等打印任务结束，保存设计，完全退出 AnkerMake Studio。
2. Windows 11：设置 → 应用 → 已安装的应用；Windows 10：设置 → 应用 → 应用和功能。
3. 搜索 **ZZXLAB · AnkerMake PhotoHub**，选择卸载；也可从开始菜单 **ZZXLAB → 卸载 PhotoHub** 运行。
4. 按卸载向导完成。卸载会验证并恢复插件管理的原版文件，保留用户设计与生成结果。
5. 从原版 AnkerMake 图标重开，确认 PhotoHub 扩展已不再加载。
6. 如果卸载提示文件被其他版本更改，保留提示并反馈，先不要手动删除原版目录。旧版没有系统卸载项时，使用对应旧版安装器的卸载入口；不要用不匹配的历史包覆盖当前版本。

## 其他限制

PSD 主要支持 8 位 RGB/灰度像素层；文字、智能对象、复杂混合与图层效果可能需预先栅格化。取样修复不是生成式填充。AI 输出是相对高度，不是真实测量。尺寸解限仍受内存、GPU 和浏览器能力约束。插件继续使用原版账号与设备连接，不提供完整 Photoshop 替代。
