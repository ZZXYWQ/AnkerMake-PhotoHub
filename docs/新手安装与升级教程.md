# AnkerMake PhotoHub 插件：新手安装与升级教程

适用版本：**PhotoHub 0.6.1 公开测试版**。请按顺序操作；首次检查不需要实际打印。

> **本项目所有公开版本均为测试版，可能存在较多 Bug；不保证及时更新或修复，没有固定更新计划。请先备份设计，并自行评估是否适合自己的工作。**

## 一、先分清三个版本

| 名称 | 是什么 | 本插件要求 |
| --- | --- | --- |
| AnkerMake Studio | 电脑上原本用于登录、设计和 UV 打印的软件 | **5.0.4** |
| 内置编辑器 | Studio 里打开设计时使用的画布资源 | **1.22.03**，相关在线模块也须通过校验 |
| PhotoHub | 本仓库提供的图片/PSD/轮廓/墨路扩展 | **0.6.1 公开测试版** |

三者不是同一个版本号。安装 PhotoHub **不会**替你升级 Studio，也不会把不兼容的编辑器变成受支持版本。

本包只支持 Windows 10 / 11 **x64**。旧版和其他新版 Studio 均不在本版适配范围。PhotoHub 0.6.0 及更早版本不要用于逐图层分墨路任务。

## 二、下载正确的原版软件

1. 打开官方 [Anker Make Studio 下载页](https://www.eufymake.com/eufymake-studio)。这是官方地址；网页域名仍保留历史品牌名。
2. 页面中找到 **Download for Windows (UV)**，选择 **UV**，不要选择 Windows (3D)、MacOS 或 Legacy Version。
3. 下载后查看安装文件的版本信息。文件名有时仍带历史品牌名，判断依据是官方来源、UV 用途和实际版本，不能只看文件名。
4. 双击官方安装文件，选择语言和安装位置，按官方安装向导完成。
5. 打开 Studio，按原版方式登录。PhotoHub 不提供新账号，也不需要你把账号或密码填进插件。

**官方网页会随时间更新，下载按钮不保证永远提供 5.0.4。** 如果当前下载到的版本不是 5.0.4，不能因为“更新”就认为能兼容本插件。请先暂停安装 PhotoHub，向官方支持咨询是否能取得 5.0.4，或等待本项目发布对应适配版。不要从本仓库寻找原版软件或 ICC；本项目不分发这些文件。

官方参考：[软件下载页](https://www.eufymake.com/eufymake-studio)、[软件用户指南](https://wiki.eufymake.com/en/softwaremanual)、[5.0 官方更新说明](https://wiki.eufymake.com/en/software/update/5-0)。本教程核对日期：2026-10-23；官方页面的布局和菜单文字可能变化。

## 三、原版 Studio 怎么升级、怎么看版本

如果已经装好了 Studio：

1. **先等当前打印任务完成。** 不要在打印中关闭软件、安装插件或升级原版。
2. 打开当前设计，按 `Ctrl+S`。如果弹出提示，选择“保存到本地”，记住 `.empf` 文件放在哪里。
3. 使用文件资源管理器，为重要 `.empf` 设计另外复制一份备份。
4. 在 Studio 的“文件 / 设置”或“帮助 / 关于”中查看当前版本。不同原版版本的菜单位置可能不同；标题栏也可能直接显示，例如 `Anker Make Studio-5.0.4`。
5. 若有“检查更新”，按原版提示操作；也可以从前述官方 **Windows (UV)** 下载入口获取原版安装器。
6. 升级完成后重新打开 Studio，再次核对是否为 **5.0.4**。若官方升级到了其他版本，请停止安装本版插件，等待对应适配。

如果已装 PhotoHub，需要更新原版 Studio：先保存项目并退出软件，使用原 PhotoHub 安装包卸载扩展，再更新原版。不要直接把旧插件文件复制进新版原版目录。

## 四、内置编辑器从哪里下载或升级

**不需要另外寻找“PhotoHub 编辑器安装包”，也不需要单独安装 PhotoCraft。** 本插件的编辑工具直接在 Studio 原画布中使用。

Studio 的原版编辑器资源由原软件加载/维护；在线画布还可能随官方服务更新。用户不应从本仓库下载一份原版编辑器覆盖进去。

查看本地已缓存的编辑器版本：

1. 打开 Windows 文件资源管理器。
2. 点击上方地址栏，粘贴下面这行，按回车：

   ```text
   %APPDATA%\eufyMake Studio Profile\cache\offline\web_res
   ```

3. 找到 `current_version.txt`，用记事本打开。里面可能是 `1.22.03`，也可能是包含该版本的完整目录路径。
4. 也可以查看同目录的 `versions` 文件夹，核对当前使用的版本。**本版要求 1.22.03**，不是看到这个文件夹存在就说明当前正在使用它。
5. 如果找不到缓存，先正常联网打开 Studio 中的设计画布，让原软件完成正常加载，再关闭 Studio 后查看。

`eufyMake Studio Profile` 是原版沿用的历史目录名，公开项目名称仍为 **AnkerMake PhotoHub 插件**。

若版本不符：通过原版更新流程获取资源，或咨询官方支持。**不要修改 `current_version.txt`、改文件夹名、删除缓存来伪装成 1.22.03。** 插件还会核对实际资源哈希；线上资源改变后也可能停止接入，需要等待适配。

## 五、下载 PhotoHub 0.6.1 公开测试版

1. 打开 [AnkerMake PhotoHub Releases](https://github.com/ZZXYWQ/AnkerMake-PhotoHub/releases)。
2. 找到 **0.6.1 公开测试版 / Public Beta**。GitHub 显示 **Pre-release** 表示公开测试版，不是完整稳定版。
3. 展开该版本下方的 **Assets**。
4. 下载这个单独的文件：

   ```text
   PhotoHub-AnkerMake-Plugin-0.6.1-Public-Beta-Win10-Win11-x64.exe
   ```

5. 普通使用者不用下载 `Source code (zip)` / `Source code (tar.gz)`，也不需要手动复制 `.js` 或 `.dll`。
6. 需要校验文件时，对照同页 `SHA256SUMS.txt`。安装器未购买商业代码签名证书；若来源或校验不确定，先停止运行并核对，不需要关闭防病毒或系统安全功能。

## 六、安装：一步一步操作

1. 确认打印任务已结束。
2. 保存设计并退出 Studio。关闭窗口后等几秒；不要让旧版 Studio 继续在后台运行。
3. 双击上一步下载的 PhotoHub EXE。
4. 安装器标题应显示 **AnkerMake PhotoHub 0.6.1 公开测试版**。
5. 安装目录通常会自动找到。如果没有找到，点“浏览”，选择**原版 Studio 的安装文件夹**，不要选择 PSD 所在文件夹，也不要选择桌面。
6. 安装文件夹里通常应能看到 `eufymake studio.exe`、`ColorEngineAPI.dll` 和 `resources`；这是宿主沿用的历史文件名。
7. 默认安装位置常见为：

   ```text
   %LOCALAPPDATA%\eufyMake Studio
   ```

8. 点 **“安装 / 升级”**，等日志明确显示安装成功。
9. 如果提示“请关闭软件”，先返回第 2 步。若提示版本或哈希不支持，不要强行覆盖；本版只能适配指定文件。
10. 从原版图标或插件创建的快捷方式启动 Studio，正常打开本地设计或新建空白画布。

**安装器只需这一个 EXE。** 不需要你另外装 Python、Node.js、独立 PhotoCraft 或另一个账号。

## 七、第一次确认插件正常：不实际打印

1. 先在普通编辑画布测试，不要在正在打印的页面测试。
2. 检查顶部 PhotoHub 工具菜单、左侧 PhotoHub 入口和原版右键菜单中的 PhotoHub 子菜单。
3. 新建一张小图片，确认能在原画布看见。
4. 选中一张图片，打开图片编辑功能，做一处明显的小改动，点击“完成编辑 / 应用”，确认修改回到画布。
5. 用一张轮廓简单的测试图做“图片转轮廓”，再右键进入轮廓形状编辑，确认节点操作有效。
6. 按 `Ctrl+S` 保存，关闭该测试设计，再重新打开，确认内容还在。
7. 此时**不必按“打印”**。本次公开验证证明的是离线打印数据流程，不代表你的机器和材料已经做过实物验证。

## 八、PSD 分层导入和每层墨路检查

1. 建议先准备一个只有 2～4 层、8 位 RGB / 灰度、普通像素图层的 PSD 副本。
2. 通过 PhotoHub 的 PSD 导入入口选择该文件，等导入结束。
3. 打开原版左侧“图层”，逐一选择各层，检查位置、上下顺序和透明度。
4. 在原版工艺设置中为每层选需要的平面、纹理等工艺。
5. 在“当前图层 CMYK”中，为第一层只选 C、第二层只选 M、第三层只选 Y、第四层只选 K（或选择你需要的组合）。
6. 来回切换这些图层，确认勾选框显示各自的设置，而不是所有层一起变化。
7. 按 `Ctrl+S` 保存为 `.empf`，重新打开后再检查一次。

`.psd` 是导入的源文件；在 Studio 内的后续设置请保存到原版项目 `.empf`，不要假定插件会回写原始 PSD。

未选彩色通道会在最终喷点数据里清零，但画布 RGB 颜色及原版预估墨量不一定随之变化；“看上去颜色没变”不能说明设置无效。半透明重叠处采用参与合成图层所允许墨路的并集；完整规则见 README。

## 九、从旧版 PhotoHub 升级

1. 0.6.0 及之前版本不要继续用于逐图层分墨路任务。
2. 等现有打印任务结束，保存所有打开的设计并完全退出 Studio。
3. 下载 **0.6.1 公开测试版** 的单文件安装器。
4. 运行安装器，确认原版安装位置正确，点击“安装 / 升级”。通常不需要先卸载旧版。
5. 出现备份/哈希异常时，不要手动删备份目录，也不要直接拷贝文件覆盖；先查看日志并提交脱敏问题报告。
6. 重新打开原 `.empf`，逐层检查墨路勾选和原版工艺，然后保存。

旧项目没有 PhotoHub 墨路字段时默认 C/M/Y/K 全选。升级不会自动猜测你希望某层使用哪一个墨路。

## 十、卸载与常见问题

### 卸载

等打印结束 → 保存设计 → 退出 Studio → 运行同一 PhotoHub 安装器 → 点击“卸载” → 重新打开 Studio。用户设计文件不会作为卸载目标删除。

### 安装窗口打不开

确认下载的是 EXE 而不是源码压缩包；确认 Windows 10/11 x64、下载完整、文件来源和校验正确。不要使用 ARM64 或 32 位机器强行尝试。

### 点击安装后报版本不支持

核对 Studio 5.0.4、编辑器 1.22.03，确认下载了 UV 版本。不同文件哈希，即使界面版本号相同，也可能是不同构建。把脱敏错误信息提交到 Issues，等待适配。

### 菜单没有出现

确认安装成功后真正退出并重开过 Studio；进入普通编辑画布，等待资源加载。原版升级或在线资源变化可能使旧适配失效，不能靠修改版本文件解决。

### 墨路勾选框没有显示

先选中**单个**图层，进入原版墨水/工艺设置面板。不要在多选、预览或打印页里寻找普通编辑面板。切换层后应显示各自的设置。

### 提交问题时写什么

写插件版本、Studio 版本、编辑器版本、Windows 版本、操作步骤、预期与实际结果。日志常见于：

```text
%LOCALAPPDATA%\EufyPhotoCraftBridge\setup.log
```

这是历史兼容目录名。只提交必要且脱敏的错误片段；不要上传 token、账号信息、私有设计或未经许可的图片。
