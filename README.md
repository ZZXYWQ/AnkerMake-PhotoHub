# AnkerMake PhotoHub 插件

**0.6.1 公开测试版（Public Beta）** · Windows 10 / 11 x64

> **本项目所有公开版本均为测试版，可能存在较多 Bug。更新和问题修复不保证及时，也没有固定更新计划。请自行评估、备份设计，不要将测试通过理解为稳定版保证。**

在 AnkerMake Studio 的原画布中编辑图片、导入 PSD 图层、识别及编辑轮廓，并为每个图层分别选择 C、M、Y、K 墨路。继续使用原软件的账号、工艺设置和打印流程。第三方社区插件，与 AnkerMake 官方无隶属或背书关系。

原软件部分安装目录、进程、缓存目录和域名仍使用历史名称 `eufyMake`；源码保留这些必要的兼容标识，不代表支持其他软件版本。

## 下载与安装

首次使用请先阅读 **[新手安装与升级教程](docs/新手安装与升级教程.md)**：包含原版软件下载、Studio/编辑器版本检查、安装、首次测试、PSD 分层、升级、卸载和排错。


从本仓库 **[Releases](https://github.com/ZZXYWQ/AnkerMake-PhotoHub/releases)** 下载：

`PhotoHub-AnkerMake-Plugin-0.6.1-Public-Beta-Win10-Win11-x64.exe`

1. 先等已有打印任务结束，保存设计并完全退出 AnkerMake Studio。
2. 运行上述单个 EXE，选择“安装 / 升级”。不需要另外安装 Python、Node.js 或独立 PhotoCraft。
3. 从原版图标或插件快捷方式启动，在普通编辑画布检查 PhotoHub 菜单。
4. 卸载时先退出软件，再运行同一个安装包，选择“卸载”。卸载保留用户设计。

安装器校验宿主、备份原文件，更新失败会尝试回滚。不包含原版软件、原版分色 DLL、ICC 配置、账号信息或测试用 PSD。

## 功能

- 图片新建、画笔/橡皮、魔术棒、矩形/椭圆选区、套索、羽化、蒙版、仿制与取样修复、渐变、色阶、曲线、调整和滤镜。
- PSD 分层导入，保留像素图层的位置、透明度和顺序；各层可独立使用原版工艺。
- 轮廓识别、图片转轮廓、节点形状编辑、简化和平滑。
- 原画布顶部菜单、左栏入口和原版右键菜单中的 PhotoHub 子菜单。
- 图层工艺合成的重叠/顶面模式，以及顶面模式的半透明忽略选项。
- 逐图层 C/M/Y/K 选择，跟随原版项目保存、撤销和重做。
- 普通编辑画布中的图片尺寸限制开关；仍受可用内存和浏览器画布能力限制。

## 墨路语义与限制

选择一个图层，在原版墨水面板中的“当前图层 CMYK”分别勾选通道。未选中的彩色墨路在最终 RIP 喷点数据中清零；白墨/光油是否存在仍由原版工艺决定。

不透明重叠处采用最上方可见图层的墨路，透明处露出下层；半透明重叠处保留参与合成图层所允许墨路的并集。**仍使用原版 RGB 合成及 ICC 分色，并非逐层独立 ICC 分色。** 画布颜色和原版用墨预估不代表筛选后的喷点。

PSD 当前支持 8 位 RGB / 灰度的像素图层；复杂混合、文字、智能对象和图层效果可能需要预先栅格化。取样修复不是生成式填充。此项目不是完整 Photoshop。

## 0.6.1 验证情况

使用本机 PSD 的四个实际图层，分别设置 C、M、Y、K，经原版浏览器卷材打包和原版本地分色内核生成四份最终 PRN：

- 检查 **548,989,024** 个打印位置，区域内未选择的彩色墨路非零数为 **0**。
- 四个彩色墨路均有真实非零喷点，避免“空白输出也通过”的误判。
- 允许喷点与**同一次**原版分色输出完全一致；白墨/光油数据未改变。
- **没有向设备发送任务，没有实际喷墨验证。** 这不等于所有工艺、硬件、机器和文件均已验证。

详见 [验证记录](docs/verification-0.6.1.json)、[测试方法](docs/TESTING.md)和 [更新记录](CHANGELOG.md)。请先用副本及小尺寸设计评估公开测试版。
