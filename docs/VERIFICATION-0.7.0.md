# 0.7.0 公开测试版验证范围

验证日期：2026-11-03。目标为 AnkerMake Studio 5.1.3、编辑器 1.23.02，本机 Windows 11 x64。所有公开版本都是测试版，可能有较多 Bug，不保证及时更新修复。

## 已完成

- 从实际桌面原版快捷方式冷启动，PhotoHub 顶部菜单、左侧入口、工艺模块与原生墨路组件正常加载。
- 新建 160×120 图片并确认可见；反色实际提交后核对原分辨率和像素；10 种像素工具启停检查。
- 图片识别转轮廓、轮廓形状编辑和平滑提交、矩形/椭圆轮廓创建；修复提交后丢失选中状态。
- PSD 三层测试文件保留图层顺序、相对位置、半透明和隐藏状态；现有四层实际设计分别设置 C、M、Y、K，互不覆盖。
- 使用原版 EMPf 保存，完全退出后重开核对四层 1/2/4/8；测试后恢复原来的 15/15/15/15（全部彩色墨路），再次保存重开核对。
- 普通 `getPrintImgRet` 与复合 `getPrintImgRetCus` 的真实新版 PNG 分别通过本地原版 RIP。每条路径四份 PRN、258,075,640 个打印像素：未选彩色墨路非零数为 0，已选喷点与同一次原生输出一致，白墨/光油和填充字节不变。
- 16 种 CMYK 组合、PNG/DDS/原生内存图片源绑定、缺失策略和畸形输入拒绝检查。
- 安装/修复/卸载与精确文件恢复、动态编辑器目录、升级后的旧缓存保护；PowerShell 5 启动执行、错误哈希拒绝、文件锁短重试和日志脱敏。
- 单 EXE 资源完整性、生产 DLL、源码敏感信息扫描；依赖均随包或由标准 Windows 提供，无需额外安装 Python、Node.js 或独立 PhotoCraft。

## 没有验证或仍有限制

- 没有向打印机发送任务，没有实际喷墨验证；不能保证全部工艺、耗材和硬件组合。
- Windows 10/11 x64 家庭/专业/企业版使用相同依赖，已做静态审核；没有逐系统虚拟机实测，不支持 32 位和 ARM64。
- 除已验证的文件/分段 RIP 整链外，额外旧版 TaskParam 纯内存整链夹具仍失败；内存源绑定通过不等于所有内存打印模式通过。
- 启动校验加入短重试和异常日志，本机最终桌面冷启动通过；此前偶发回退的根因尚未完全确诊。
- 墨路是原版 RGB 合成及 ICC 分色后的喷点筛选，并非逐层独立 ICC 分色。画布颜色与原版用墨估算不等于筛选后的喷点。
- 官方在线模块变化后需要重新验证，旧版或其它新版 AnkerMake 不在本包适配范围。

原始 PSD、PNG、PRN、ICC、原版 DLL、账户数据和原始日志均不公开。汇总见 [verification-0.7.0.json](verification-0.7.0.json)。
