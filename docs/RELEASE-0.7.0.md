# AnkerMake PhotoHub 插件 0.7.0 公开测试版

**所有版本均为测试版，可能存在较多 Bug；不保证及时更新或修复，没有固定更新计划。** 本次以 Pre-release 发布。

适配 **AnkerMake Studio 5.1.3 + 编辑器 1.23.02**。0.6.x 安装包不能用于这个新版环境。Windows 10/11 **x64** 家庭、专业、企业版共用同一个安装包，依赖已内置，无需额外安装 Python、Node.js 或独立 PhotoCraft；尚未逐一实测所有系统版本。

## 下载与安装

下载 `PhotoHub-AnkerMake-Plugin-0.7.0-Public-Beta-Win10-Win11-x64.exe` 即可，`SHA256SUMS.txt` 用于可选完整性校验。原版软件不包含在插件中。

等正在进行的打印结束，保存设计并退出 Studio，运行安装包选择“安装 / 升级”。之后从原版桌面图标或插件快捷方式启动。卸载仍使用同一个 EXE，不删除设计文件。

详细步骤见 [新手安装与升级教程](https://github.com/ZZXYWQ/AnkerMake-PhotoHub/blob/main/docs/新手安装与升级教程.md)，包括原版 UV 软件下载与更新、版本检查、安装、PSD 分层、升级和卸载。

## 本次变化

- 适配新版在线编辑器、工艺导出及原生 CMYK 路径，保留严格版本和哈希校验。
- 改进当前画布发现与项目单例共享，修复轮廓提交后的选中状态。
- 启动入口动态读取当前编辑器目录，保留本机所需的原版启动参数；增加严格流式校验、短重试和脱敏启动日志。
- 新建、编辑图片、图片转轮廓及形状编辑、PSD 图层位置/透明度/顺序和每层 CMYK 已做本机验证。
- 四层墨路保存后完全退出重开验证通过，测试后恢复原设置。
- 两条真实导出路径分别校验 258,075,640 个本地 RIP 打印像素，未选彩色墨路均为零。**没有实际打印。**

验证细节和未覆盖情况见 [验证范围](https://github.com/ZZXYWQ/AnkerMake-PhotoHub/blob/main/docs/VERIFICATION-0.7.0.md)。额外旧版纯内存整链夹具尚未通过；不能把本次结果理解为所有打印模式或所有电脑的稳定性保证。
