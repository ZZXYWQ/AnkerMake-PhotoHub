## 超长打印：当前版本必须遵循的导入方向

**必须先按横向长图导入，再在 AnkerMake 软件里面旋转 90°，然后选择“超限图片优化算法”。**

1. 准备横向长条原图，宽度大于高度。例如本轮文件为 51160×1924 像素。
2. 以横向状态导入 AnkerMake，再使用软件画布里的旋转功能设置为 90°，让长边沿卷材进给方向排列。
3. 旋转后核对最终打印宽度 W、卷材长度 L 和画面朝向；保持所需物理尺寸与比例。
4. 在黑色“打印”按钮右侧箭头中选择“超限图片优化算法”，再按原版准备流程操作。

**旋转必须在 AnkerMake 软件内完成；不要先在其他图片软件中转成竖图，再直接导入。** 当前竖向图片直接导入的超长路径仍不可靠，不能将横向导入后旋转的实测结果推广到所有方向。

2026-11-28 用户反馈：清明上河图按“横向导入 → 软件内旋转 90°”后可正常打印。这是用户实测反馈，不代表任意图片、工艺或设备均完成实物验收。普通尺寸的原版打印算法不受此条超长流程要求约束。
