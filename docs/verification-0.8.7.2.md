# 0.8.7.2 LongRollFix2 验证范围

全部为公开测试版，可能有较多 Bug，不保证及时更新和修复。

- 适配 AnkerMake Studio 5.1.3、编辑器 1.25.04、Windows 10/11 x64；其他宿主版本不支持。
- 超限卷材导出包使用本段像素高度换算物理高度；普通算法保留原有路径。
- 临时打印副本的超长源图绘制先裁定可见范围，避免提交超大目标矩形；不修改原始图片或画布尺寸。
- 真实 1924×51160 / 约 280×7445mm 源图，经正式网页打印管理器的方法生成全部 74 段。设备命令及上传回调被拦截，没有下发设备任务。
- 74 个彩色包非空、无重复；73 个连接处检查，整体回拼灰度相关度 0.998259。该数值不是打印质量评分。
- 修正后的首中末 PNG 经独立原生 RIP，各生成四份 PRN；物理尺寸约 280×28.45mm / 280×101.6mm / 280×101.6mm。独立测试显式提供逐段毫米布局，不能证明正式宿主使用了同一布局。
- 当前浮雕配置另生成三个段，彩色与高度图非空；不代表整张浮雕打印通过。
- JS 回归、精确模块适配和新增长图绘制/尺寸测试通过。

**未完成：正式宿主 TAR 到原生布局、最终设备数据转换的运行时核对，以及实物打印验收。条纹是否彻底修复尚不能下结论。**

Windows 设置“已安装的应用”中的 PhotoHub 可卸载插件；先保存并关闭 Studio。不会删除用户设计。
